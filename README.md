# 🚀 WebDev Academy

Plataforma e-learning desarrollada en **PHP y MySQL**, inspirada en plataformas modernas como Udemy.

Proyecto desarrollado como plataforma full-stack dentro del ciclo de Desarrollo de Aplicaciones Web (DAW).

---

# ✨ Características

- Sistema de usuarios y roles
- Plataforma de cursos online
- Sistema de lecciones
- Seguimiento de progreso
- Exámenes dinámicos
- Certificados PDF
- Panel de administración
- Buscador y filtros
- Valoraciones y comentarios
- Diseño responsive
- Arquitectura modular
